# 计划睡眠区间即真实睡眠时间

用户没有专业设备（多导睡眠仪等）测算实际睡眠，且实际作息与计划基本一致。因此本项目将"计划睡眠区间"（联动设定的入睡时刻 + 起床时刻）直接作为真实睡眠时间写入 `sleep_record` 的现有字段，**不区分"计划值"与"实际值"**——不新增 planned 字段、不新增计划表、不做数据库迁移。

这意味着：统计口径中的"睡眠时长"就是计划区间的时长。若未来引入设备数据或双轨记录，需要一次 schema 迁移，属可接受的升级路径。

## Considered Options

- **同表加 planned/actual 双字段**：支持计划偏差分析，但用户明确表示按计划执行、无实测手段，双轨是多余的复杂度。
- **独立 sleep_plan 表**：隔离清晰，但统计需 join，且绝大多数日子计划=实际。

## Consequences

- 记录校验需放宽为"允许明天"（晚间设定闹钟要写入次日的睡眠日），半成品记录合法但不计入统计。
- 午睡同理：设小睡预设时按预设时长写入，即"计划午睡=实际午睡"。
